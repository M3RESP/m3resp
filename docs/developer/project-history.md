# Project stages

These pages describe the three stages of the project. In stage 1, M3Resp called `eitprocessing` and `resurfemg` through one session and one workflow engine. Stage 2 added the shared data objects and the data model. Stage 3 is the plan to move the EIT and EMG processing into M3Resp.

The pages give the reasons for the design. See {doc}`architecture` for the code as it is now.
