# SWITCH-SAFE figures overview

Overview of all figure types generated by the SWITCH-SAFE workflow pipeline,
their data sources, and the functions that produce them.

All paths are relative to the repository root.

---

## 1. Boxplots (`figures/SWITCH-SAFE/statistical_analysis/boxplots/` — 14 files)

### Per-method boxplots (12 files)

**Filename pattern:** `boxplots_{emc|individual}_preprocessing_{method}.png`

**What it shows:** Grouped boxplots of pendelluft values across all datasets (PC and PS groups).
Shows both per-patient medians (solid box) and individual breath distributions (lighter boxes).

**Generator:** `pendelluft_workflow/workflow/plots/boxplots.py` → `plot_method_dataset_boxplots()`

**Data source:** `csv_results/SWITCH-SAFE/{prep}/breath_by_breath/pendelluft_results_{prep}_breath_by_breath.csv`

---

### Summary statistics boxplots (2 files)

**Filename pattern:** `summary_statistics_boxplots_{emc|individual}.png`

**What it shows:** All 5 methods on the x-axis, PC vs PS as side-by-side coloured boxes.
Each box represents the distribution of per-patient medians across the study cohort.

**Generator:** `pendelluft_workflow/workflow/plots/boxplots.py` → `plot_summary_statistics_boxplots()`

**Data source:** Patient medians aggregated from the same breath-by-breath CSVs above.

---

## 2. Prevalence (`figures/SWITCH-SAFE/prevalence/` — 2 files)

### ROC curves

**Filename:** `roc_curves.png`

**What it shows:** One ROC curve per method showing how well each method discriminates PS
(elevated pendelluft) from PC (baseline). Marks AUC and the Youden-optimal threshold per method.

**Generator:** `pendelluft_workflow/workflow/plots/prevalence.py` → `plot_roc_for_methods()`

**Data source:** All breath-by-breath CSVs; PC timestamps are used as the reference (negative)
class and PS timestamps as the positive class. Aggregated to patient medians before ROC computation.

---

### PC vs PS histograms

**Filename:** `pc_vs_ps_histograms.png`

**What it shows:** One subplot per method — histogram of patient-median pendelluft split into
PC (gray) vs PS (blue) populations, with 95th-percentile and Youden threshold lines overlaid.

**Generator:** `pendelluft_workflow/workflow/plots/prevalence.py` → `plot_pressure_control_vs_support_histograms()`

**Data source:** Same breath-by-breath CSVs, aggregated to patient medians per timestamp group.

---

## 3. LME / regression figures (`figures/SWITCH-SAFE/statistical_analysis/` — 3–4 files)

### Pendelluft model results (appears twice: timing + clinical version)

**Filename:** `pendelluft_model_results.png`

**What it shows:** Two-panel figure —
- Panel A (forest plot): standardised fixed-effect coefficients with 95% CI, coloured by significance (p < 0.05).
- Panel B (stacked bar): variance decomposition into between-patient intercept / method variation / within-patient residual.

**Generator:** `pendelluft_workflow/workflow/plots/lme.py` → `plot_fixed_effects_variance_decomposition()`

**Data source:**
- *Timing version:* breath-by-breath CSV + computed timing metrics (respiratory rate, T_insp/T_tot, global inhomogeneity).
- *Clinical version:* merged table combining pendelluft medians with PEEP, P_occ, P_0.1, tidal volumes, P/F ratio, and PES swings — pulled from multiple external clinical CSVs.

---

### Predictors vs pendelluft (appears twice: timing + clinical)

**Filename:** `predictors_vs_pendelluft.png`

**What it shows:** Grid of scatter plots — one panel per clinical predictor, predictor on x-axis,
z-scored pendelluft on y-axis, with one regression line per method.

**Generator:** `pendelluft_workflow/workflow/plots/lme.py` → `plot_predictors_vs_pendelluft()`

**Data source:** Same merged dataset as the model results above.

---

### Residual diagnostics

**Filename:** `residuals_*.png`

**What it shows:** Three-panel QA figure — histogram of residuals, Q-Q plot (normality check),
and residuals vs fitted values (heteroscedasticity check).

**Generator:** `pendelluft_workflow/workflow/plots/lme.py` → `plot_residual_diagnostics()`

**Data source:** Residuals extracted directly from the fitted `statsmodels` LME model object.

---

### Timing slopes

**Filename:** `lme_slopes_timing.png`

**What it shows:** For each method — two slope estimates (respiratory rate effect and inspiratory
time ratio effect on pendelluft) with 95% CI error bars.

**Generator:** `pendelluft_workflow/workflow/plots/lme.py` → `plot_method_slope_pairs()`

**Data source:** Coefficients extracted from a fitted LME model on timing metrics.

---

## 4. GI-LME (`figures/SWITCH-SAFE/statistical_analysis/gi_lme/` — 2 files)

### GI regression grid

**Filename:** `regression_gi.png`

**What it shows:** 2×3 subplot grid — one scatter + regression line per method showing global
inhomogeneity (x) vs standardised pendelluft (y), plus an "all methods" combined panel.

**Generator:** `pendelluft_workflow/workflow/plots/lme.py` → `plot_method_regression_grid()`

**Data source:** Breath-by-breath CSV (requires `global_inhomogeneity_value` column).

---

### GI method slopes

**Filename:** `slopes_gi.png`

**What it shows:** Point-and-CI plot — one slope estimate per method for the GI → pendelluft
effect, derived from a mixed-effects model with `pendelluft ~ GI × method + (1|patient)`.

**Generator:** `pendelluft_workflow/workflow/plots/lme.py` → `plot_simple_method_slopes()`

**Data source:** Coefficients extracted from the fitted GI-LME model.

---

## 5. Patient-level diagnostic plots (`figures/SWITCH-SAFE/{patient}/{timestamp}/{prep}/{method}/`)

Generated per patient, per timestamp, per preprocessing mode, per method — used for visual QC
of the pendelluft detection algorithms.

| Filename | What it shows |
|---|---|
| `plot_FRIC_i.png` | Functional residual impedance change — EIT pixel frame at inspiration start |
| `plot_global_inspiration_start.png` | Global EIT signal with detected breath starts marked |
| `plot_pixel_impedance_derivatives.png` | Pixel-by-pixel derivative of EIT signal (Adler & Sang) |
| `plot_early_late_roi_detection.png` | Early vs late-filling ROI detection (Coppadoro method) |
| `plot_roi4_breath_detection.png` | Quadrant-based ROI breath detection (Cornejo method) |
| `plot_pendelluft_map.png` | 32×32 pixel heatmap of pendelluft values (Menga & Sang) |

**Generator:** Method-specific `plot_*()` functions inside `src/plotting/plotting_{method}.py`

**Data source:** Raw EIT pixel arrays (`.npy` / `eitprocessing` format) + detected breath
timings from the preprocessing step.

## Summary table

| Category | File count | Primary data source |
|---|---|---|
| Per-method boxplots | 12 | Breath-by-breath CSVs |
| Summary boxplots | 2 | Patient medians aggregated from breath-by-breath |
| ROC + histograms | 2 | Breath-by-breath CSVs + PC/PS timestamp labels |
| LME model results + predictors | 3–4 | Merged clinical + pendelluft + respiratory data |
| GI regression | 2 | Breath-by-breath CSVs with GI values |
| Patient QC plots | ~30+ per run | Raw EIT arrays + breath detections |

> **Note on clinical LME figures:** These are the only figures that pull from external sources
> (PEEP, P_occ, tidal volumes, body weight, PES swings). All other figures derive purely from
> the pendelluft method CSVs produced by the pipeline itself.
