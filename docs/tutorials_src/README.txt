Tutorials
=========

Each tutorial takes you through one complete analysis, from the recording files to the result files. Every step shows the output that you will see on your computer. The documentation build runs each tutorial, so the printed values and the figures come from the real code.

The tutorials use the synthetic recordings in the ``tests/data`` folder of the M3Resp source code. Install M3Resp with the EIT and EMG integrations (``python -m pip install -e ".[all]"``) and run the scripts from the M3Resp source folder. Each tutorial page has a link at the bottom to download it as a Python script or as a Jupyter notebook.

Do the tutorials in this order. Each tutorial uses one :term:`modality`.
