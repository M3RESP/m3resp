# M3Resp

M3Resp provides one workflow for respiratory measurements collected with
electrical impedance tomography (EIT), respiratory electromyography (EMG), and
ventilator systems. It keeps sampling rates, units, signal labels, processing
history, and data provenance visible while coordinating the modality-specific
processing packages.

Use the [getting started guide](getting-started.md) for installation and a first
pipeline run. The [tutorials](tutorials/index.md) provide complete workflows,
while the [concept guides](concepts/index.md) explain the scientific data model.
