Selected windows

Each lane is a min/max overview of the same signal shown in that modality's section above — the ventilator lanes follow whichever channels are ticked there. Drag a handle to resize a window, drag its band to move it, or click + Add window to select another range — click a window (on the canvas or in the list) to edit it with the Start/End fields above. Save as new sequence concatenates every window above, in time order, into one named sequence — the same effect as chaining eit.slice + Sequence.concatenate() — and adds it to the persistent Saved sequences library below.

Saved sequences

This library persists across datasets — load different data above, slice a fresh set of windows, and save again; every sequence you've named stays here and keeps showing up under Available data on 2 · Design.
