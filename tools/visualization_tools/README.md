# Visualization tools

Three interactive [Marimo](https://marimo.io) notebooks for exploring the pendelluft data and workflow results.

## Apps

| File | Description |
|---|---|
| `visualize.py` | Raw synthetic data explorer — ventilator, EIT global signal, EIT pixel heatmap, EMG, session metadata |
| `workflow_results.py` | Workflow results explorer — pendelluft summary boxplot, breath-by-breath timeseries, prevalence analysis, PES swings |
| `compare_pes_preprocessing.py` | Pes preprocessing comparison — runs Pes preprocessing methods on a chosen segment and compares their filtered signals / peak detections |

## How to run

All commands are run from the **repository root** (`LotteKuiper_thesis_pendelluft/`).

### 1. Activate the virtual environment

```bash
source .venv/bin/activate
```

### 2. Launch an app

**Raw data explorer:**
```bash
marimo edit visualization_tool/visualize.py
```

**Workflow results explorer:**
```bash
marimo edit visualization_tool/workflow_results.py
```

**Pes preprocessing comparison:**
```bash
marimo edit visualization_tool/compare_pes_preprocessing.py
```

Marimo will print a local URL (e.g. `http://localhost:2718`) and open it in your browser automatically.

### Run as a read-only app (no code editor visible)

```bash
marimo run visualization_tool/visualize.py
marimo run visualization_tool/workflow_results.py
```

## Data requirements

| App | Reads from |
|---|---|
| `visualize.py` | `Data/synthetic/<session>/` — CSV and NumPy files generated by the synthetic data pipeline |
| `workflow_results.py` | `pendelluft_workflow/output/<run>/` — CSV outputs of the SWITCH-SAFE workflow pipeline |
| `compare_pes_preprocessing.py` | Segment pickle files under `Data/` (or an absolute path you enter in the app) |

Both paths are resolved relative to the repository root, so the apps can be launched from any working directory as long as the repo structure is intact.
